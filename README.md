# PWC Race Control

Prototype for a jet ski race-management platform.

## First prototype
- Race-day organiser dashboard
- Race schedule and rider counts
- Live scoring entry point
- Rider management entry point
- Push-notification mockup for briefings and race calls
- Responsive mobile layout

## Product direction
The platform is intended to support organisers, officials and riders with entries, classes, heats/motos, scoring, results and race-day communications. Rider notifications remain part of the free/freemium experience, with advanced organiser features suitable for paid tiers.

## Run locally
```bash
npm install
npm run dev
```
Then open `http://localhost:3000`.
